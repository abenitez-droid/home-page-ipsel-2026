# Contenido de demostración (ficticio)

> **SOLO PARA MAQUETACIÓN.** Todo el contenido de este archivo es inventado y no describe datos, servicios, actividades ni decisiones reales del Colegio IPSEL. No copiarlo a las páginas publicables ni presentarlo como información institucional. Reemplazarlo por contenido validado por la institución antes de publicar.

Este material permite probar la estructura y el diseño de las páginas mientras se recopila la información real. No contiene nombres de personas ni datos de contacto utilizables.

> **Ya implementado:** el contenido de muestra que consume el sitio vive en `js/data/*.data.js` (una fuente por página) y se inyecta con `npm run build`. Cada fuente tiene dos partes: `textos` (los textos fijos, referenciados desde el HTML con `data-tx="clave"`, con su tipografía opcional en `tipoFuente`/`tamano`/`color`) y los bloques repetidos/`ui`. El build genera además la tipografía en `css/pages/<pagina>/tipografia.css`. Este documento queda como referencia editorial; para cambiar lo que se ve en las páginas, editá los `js/data/*.data.js` y volvé a ejecutar el build.
